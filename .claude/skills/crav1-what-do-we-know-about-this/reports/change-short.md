# report-change-short

One screen: what one change does and where it stands. Rules: `reports/common.md`.

Diagrams: one `flowchart` of before → after, or a `gitGraph` when the point is branches and merges. No C4.

```markdown
# <Change>: what it does

## Verdict
<one line>

## The 30-second version
<3–5 bullets: what changes, why, what is agreed, what is open>

## What changes
<diagram, then the files or parts that change>

## Source
<pull request, branch, files, live reads>
```
