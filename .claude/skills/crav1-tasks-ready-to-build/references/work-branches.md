# Work branches

**Branches (1.64.0).** When the slice has work branches (`Synced at` lines, Match `Branch:` entries, and `(branch: …)`, minus base branches and `(dropped)` entries), add the Branches line under the counts from skill `crav1-add-to-spec`, `references/branches.md` (local git only: contained, or the same change by `git cherry`). No host check here, so a squash merge can show as not merged; say `squash merges are checked by /crav1-help status`. A shared branch gets `(also in <slug>)`. Report only. They do not change readiness or the Done count.
