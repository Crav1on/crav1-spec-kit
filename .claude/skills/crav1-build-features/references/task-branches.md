# Task branches (1.140.0)

Read only when `SKILL.md` says `--recommend`'s first line is not `feat/<slug>`. Do not open this file otherwise. The rules are unchanged.

**Task branches (1.140.0).** Inside a slug, a task is built on the first line of `scripts/build_map.py docs/specs/<slug> --recommend T#` (skill `crav1-tasks-ready-to-build`). A branch named on the task line wins over the plan step. On that line, `(map:)` wins, then `(branch:)`. A merged or deleted branch is not used. Switch to it before its worker, only on a clean tree (`git checkout X`, which also makes the local branch from `origin/X`). A name that is a base branch is `blocked` with `branch X is a base branch`; never switch to it. Starting the board is consent to these switches when the branch exists. When the name exists nowhere, use the task-branch card once. Open `../crav1-create-feature-branch/references/task-branch.md` from this skill's folder. The rule is [open-skill-file.md](../crav1-docs/reference/open-skill-file.md) (1.134.0). Do not start `/crav1-create-feature-branch`. Do not invent a different recommended name, and do not create it without a yes. A name for another repo is `blocked` with `belongs to <repo>`.
