# Pointed at a research note

When the user replaced a file under `docs/research/` and pointed this command at it, follow the clear section of `crav1-add-to-spec` `references/research-stale-clear.md` (drop-in: `.cursor/skills/crav1/crav1-add-to-spec/references/research-stale-clear.md`; plugin: sibling `skills/crav1-add-to-spec/references/research-stale-clear.md`). Do not ask whether the update resolves the mark. Judge each listed point from the update's text. An older mark with no point lines is not one point. Split it as that file says. Also route the note's own open questions when the answer lies outside the note's owner. That still runs when the mark clears. Clear the mark only when every listed point is resolved, or when an older mark had no points and the update resolves the original quote. Otherwise narrow the mark and route each open point. When the older mark had no points and stays open, leave it as written. Record `Cleared <date>: updated note <path or commit>.` under `## Research findings` only when the mark clears, with one short line per point when the mark had points. Do not send anything. Drafts stay in the chat. This check does not replace the picture update. The picture still follows **Write** in SKILL.md. The clear's writes on the note and on `spec.md` are part of this check.
