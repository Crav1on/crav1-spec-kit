# crav1-review-pr: posted comments

Read only when the pointer in `SKILL.md` sends you here. Moved word for word from `SKILL.md` in 1.71.0; the rules are unchanged.

## Comment as posted first

When the PR note (or an old follow-ups note) for this pull request has a `## Comment as drafted` section with no `## Comment as posted` section after it, or the posted comment may have been edited on the host, run the **record step** before the review. Find the posted comment on the host (read-only) or ask for a paste. Save it word for word in a code fence under `## Comment as posted, <YYYY-MM-DD> (by <name>)`. Compare it with the draft, and tag drafted points left out `not posted <YYYY-MM-DD>` on their record Point without dropping them (1.97.0). How to find, pick, compare and mark: `references/comment-as-posted.md` (this skill's `references/comment-as-posted.md`). The `comment posted` choice word runs only this step.
