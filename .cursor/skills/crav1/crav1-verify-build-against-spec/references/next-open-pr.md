# Open a pull request

All verified, and a work branch is not merged. The step (1.168.0): reason `Built and verified, not merged yet: <branches>.`, label `Open the pull request:`, command `/crav1-open-pr`. A branch with `(PR <n>)` names it: label `Update PR <n>:`, `/crav1-open-pr` to push to PR <n> and update its description or comment.
