# Slice branches (1.64.0)

Read only when `SKILL.md` says so.

**Branches (1.64.0).** When the slice has work branches (`Synced at` lines, Match `Branch:` entries, and `(branch: …)`, minus base branches and `(dropped)` entries), add the Branches line under the counts from skill `crav1-add-to-spec`, `references/branches.md` (local git only: contained, or the same change by `git cherry`). No host check here, so a squash merge can show as not merged; say `squash merges are checked by /crav1-help status`. A shared branch gets `(also in <slug>)`. **Sub-branches and reverts (1.68.0)** use `(into <spec branch>)`. They are that same file, under those headings. Report only. They do not change readiness or the Done count.
